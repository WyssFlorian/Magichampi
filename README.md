# Magichampi

Cartes des forêts favorables aux champignons comestibles (Riviera-Chablais, Région lausannoise, Gros-de-Vaud).
Ouvrir le site, choisir une carte, toucher ◎ pour suivre sa position, « Hors ligne » pour la télécharger.

Ne consommez aucun champignon sans le contrôle d'un contrôleur officiel (VAPKO).

Site généré par `tools/build_pages.py` du dépôt source (privé). Ne pas modifier les fichiers à la main.
